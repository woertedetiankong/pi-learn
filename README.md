# pi-learn

用你自己的材料出题自测的 [pi](https://pi.dev/) 插件：从**和 AI 的对话记录**、**知识库文档**里挑材料，让 AI 出选择题、填空题、解答题，每道题都标出原文出处，并给出答案和解析。

它和 [pi-sessions](https://github.com/woertedetiankong/pi-newsession)（会话）、pi-kb（知识库）共用同一个本地网页：页面顶部可以在「会话 / 知识库 / 学习」之间切换，访问令牌也是同一个。

## 功能

1. **选材料**：勾选任意几段对话（会话插件提供）和知识库文档（知识库插件提供），PDF 这类分页文档可以只选某几页。可以填「重点」，材料太长时优先保留提到重点的段落。
2. **出题**：选择题（单选 / 多选）、填空题（一个题可以有多个空，每个空接受多种写法）、解答题（参考答案 + 评分要点），可调数量和难度。
   每道题带 **出处**：来源是哪段对话的第几条消息、或哪份文档的第几页，附原文引句；插件会核对引句是否真的出现在原文里，找不到会标出「原文中未找到这句原话」。点「看原文」展开原段落（引句高亮），点「打开对话 / 在知识库打开」跳到对应页面。
3. **答案和解析**：选择题、填空题提交后立即判分；解答题可以「AI 批改」（按要点打分并指出缺了什么），也可以对照参考答案自评。填空题判错时可以让 AI 复核（比如同义写法）。
4. **问 AI 老师**：每份测验右侧有独立的对话框，AI 能看到材料、题目和你的作答，可以追问某道题、总结错因，也可以让它「再出 3 道更难的题」，新题会追加到测验末尾。
5. **选模型**：页面右上角选模型（默认跟随 pi 当前模型），出题、批改、对话都用它。

这些 AI 调用直接走 pi 的模型注册表（`modelRegistry.complete`），**不进入、也不影响 pi 里正在写代码的会话**。

测验保存在 `~/.pi/agent/pi-learn/quizzes/`（可用 `PI_LEARN_DIR` 改），材料随测验一起保存，原对话或文档删了以后仍能查看出处。

## 安装

```bash
pi install git:github.com/woertedetiankong/pi-learn     # 或本地路径：pi install /path/to/pi-learn
```

从对话出题需要安装 pi-sessions，从知识库出题需要安装 pi-kb；只装其中一个也能用，另一类来源会显示「未安装」。

## 使用

| 命令 | 作用 |
| --- | --- |
| `/learn` | 在浏览器打开学习页面 |
| `/learn url` | 只显示页面地址 |
| `/learn stop` | 停止网页服务（会话、知识库页面共用，也会一起停止） |

链接：`/learn/?quiz=<id>` 直接打开某份测验。

## 和另外两个插件怎么配合

三个插件各自带一份相同的 `src/hub.ts`，在进程里通过 `globalThis.__piWebHub` 共用一个本地 HTTP 服务：

- `/learn/` 页面、`/api/learn/...` 接口由本插件提供；
- 读取材料时，本插件在进程内直接调用会话插件的 `/sessions`、`/transcript` 和知识库插件的 `/docs`、`/doc` 接口，不重复解析它们的文件格式；
- 出处链接用会话页的 `/sessions/?id=<会话 id>` 和知识库页的 `/kb/?doc=<id>&page=<页>`。

`src/hub.ts` 必须和另外两个插件里的保持一字不差（见文件开头的说明）。
